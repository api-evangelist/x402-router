# x402-router

ForgeMesh Router (x402 Router) is a paid, ranked service-discovery registry for x402 endpoints. Agents query GET /api/services to discover paid services and their x402 payment metadata. Access is gated by the x402 payment protocol (USDC on Base, ~$0.001 per query) rather than API keys.

- **Provider:** https://router.forgemesh.io
- **Documentation:** https://router.forgemesh.io
- **Base URL:** https://router.forgemesh.io

## APIs

- **ForgeMesh Router Discovery API** — REST/HTTP x402-paid discovery registry. GET /api/services returns ranked x402 service listings with provider name, url, category, reputation_score, pricing, and x402 payment metadata. Gated by the x402 402-challenge micropayment flow (USDC on Base). (`https://router.forgemesh.io`)
